Simple Home & Contact Page Website

This is a simple website created using HTML and CSS.
It includes two pages:

* 🏠 Home Page – A simple introduction and basic website layout.
* 📞 Contact Page – A basic contact section for visitors to get in touch.

Technologies Used

* HTML5
* CSS3

This project was created as a beginner-level practice project to learn HTML page structure, CSS styling, navigation, and linking multiple pages.
